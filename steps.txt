1) Create a github repo
    - Create a folder (i created ML Projects)
    - Go to "anaconda prompt". and then cd to the folder path.
    - then type "code ." --> this will create a vs code instance.

2) We need to create a new environment.
    - Wtv libraries we install, will get installed in this env only.
    - type this in vsc terminal :
    - conda create -p venv python==3.8 -y
    - conda activate venv/

3) Now we need to sync our folder with our github repo.
    - git init (in our vsc terminal)
    - then create a README.MD file in our folder manually.
    - git add README.md
    - git commit -m "First Commit"
    - git status
    - git branch -M main
    - git remote add origin https://github.com/Vrushti-123/ML-Projects.git
    - git remote -v
    - git push -u origin main
    Then reload the github page and you'll see your repo.

4) Setting up: Creating setup.py --> this will be responsible for creating/building my ML application as a package.
    we can install this package in our projects and use it.
    then even deploy it in python py py --> anybody can install and use it.
    - create two files: setup.py and requirements.txt
    - create a folder called src
    - create a file inside src --> __init__.py

5) Inside requirements.txt --> "-e ."
whenever we are trying to install the requirements.txt,
at that time the setup.py should also run to build the packages.
so, -e . --> this will trigger the setup.py file.

So, when we type "pip install -r requirements.txt" 
Now, because of the "-e ." --> mapped to setup.py --> automatically this entire package will get built.

After running this command -->  we can see that a folder gets created by itself.
mlproject.egg-info --> now we can use these package anywhere if we deploy it in py py.
